# Running Pace & Split Calculator 🏃‍♂️⚡

Una aplicación web interactiva y de alto rendimiento diseñada para corredores que buscan calcular con precisión milimétrica sus tiempos totales y parciales por kilómetro. 

Construida con un enfoque estético **brutalist** (minimalista, de alto impacto visual y centrada por completo en la claridad de los datos).

---

## 🚀 Características Principales

* **Cálculo Dinámico**: Ingresa tu distancia y ritmo objetivo para obtener el tiempo total estimado al instante.
* **Tabla de Parciales (Splits)**: Desglose automatizado kilómetro a kilómetro con el ritmo específico y el tiempo acumulado.
* **Diseño Brutalista**: Estética moderna con contrastes marcados, tipografía de gran impacto y una interfaz completamente libre de distracciones.
* **Responsive**: Adaptada para usarse cómodamente tanto en dispositivos móviles en plena ruta como en ordenadores.

---

## 🛠️ Stack Tecnológico

* **React** 
* **TypeScript**
* **Vite**
* **Tailwind CSS v4** (con diseño personalizado)
